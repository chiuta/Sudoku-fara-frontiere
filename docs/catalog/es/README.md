# Catálogo de variantes (136)

[English](../en/README.md) · [Română](../README.md) · [Français](../fr/README.md) · [Italiano](../it/README.md) · **Español** · [Português](../pt/README.md) · [Deutsch](../de/README.md) · [Magyar](../hu/README.md)

[← README](../../../README.es.md)


Cada variante tiene debajo: las reglas de la ficha, una captura con un puzle real generado por la aplicación (tamaño 9×9 donde existe, si no el más pequeño; nivel «medio»), una segunda captura tras 4 pasos de «Paso a paso», la explicación real del último paso y un código con el que regeneras exactamente el mismo puzle. Bajo cada variante, una «Galería completa» (desplegable) contiene los demás tipos de capturas: la tarjeta del Atlas y la ficha, todos los tamaños, fácil/medio/difícil, notas automáticas, comprobación con un dígito erróneo, la solución completa, el tema oscuro, el teléfono, la interfaz en inglés y el panel de reglas. Todas proceden de `../../screens/` (en `screens.zip`). Las capturas se hicieron automáticamente a partir de la versión 1.4.0, en tema claro.
