# A változatok katalógusa (136)

[English](../en/README.md) · [Română](../README.md) · [Français](../fr/README.md) · [Italiano](../it/README.md) · [Español](../es/README.md) · [Português](../pt/README.md) · [Deutsch](../de/README.md) · **Magyar**

[← README](../../../README.hu.md)


Minden változathoz az alábbiak tartoznak: a szabálykártya szabályai, egy, az alkalmazás által előállított valódi rejtvényről készült képernyőkép (9×9-es méretben, ha van, különben a legkisebben; „közepes” szint), egy második képernyőkép a „Lépésről lépésre” 4 lépése után, az utolsó lépés valódi magyarázata, és egy kód, amellyel pontosan ugyanazt a rejtvényt újragenerálhatod. Minden változat alatt egy „Teljes galéria” (lenyitható) tartalmazza a képernyőképek további típusait: az Atlasz-kártyát és a szabálykártyát, az összes méretet, könnyű/közepes/nehéz szintet, az automatikus jegyzeteket, az ellenőrzést hibás számjeggyel, a teljes megoldást, a sötét témát, a telefont, az angol felületet és a szabálypanelt. Mindez a `../../screens/` mappából származik (a `screens.zip`fájlban). A képernyőképek automatikusan készültek az 1.4.0-s verzióból, világos témában.
