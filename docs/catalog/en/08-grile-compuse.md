#### 95. Sohei (ring of four) · Sohei (ring of four) (`sohei`)

**Four 9×9 grids linked in a diamond ring.**

Four 9×9 grids are placed in a diamond (top, right, bottom, left); each two neighbouring grids share a 3×3 box (four shared boxes in all) and a hole remains in the middle. Every row, column and box holds each digit once; digits in shared boxes count for both grids. The geometry is a convention chosen here; sources differ.
