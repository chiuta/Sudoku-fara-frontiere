<a id="clasic"></a>
#### 1. Classic (`clasic`)

**Row, column, box: each digit once.**

Fill the grid so every row, column and box contains each digit exactly once. Sizes: 4×4 (mini), 6×6 (2×3 boxes), 8×8 (2×4), 9×9, 12×12 (3×4), 16×16 (symbols 1–9 and A–G) and 25×25 (1–9 and A–P).

**Letters instead of digits.**

<a id="zero"></a>
#### 4. Zero Sudoku (`zero`)

**Digits run from 0 to N−1.**

The same game as Classic; only the symbols differ: 0…N−1 (at 9×9: 0–8). The rules are the classic ones, so this is more of a display variant.
