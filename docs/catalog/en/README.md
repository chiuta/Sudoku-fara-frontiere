Below, each variant has: the rules from its sheet, a screenshot of a real puzzle generated by the app (size 9×9 where it exists, otherwise the smallest; “medium” level), a second screenshot after 4 “Step by step” steps, the app’s real explanation of the last step, and a code with which you can regenerate exactly the same puzzle. Under each variant, a “Full gallery” (collapsible) holds the other screenshot types: the Atlas card and the rules sheet, all sizes, easy/medium/hard, auto-notes, checking with a wrong digit, the full solution, the dark theme, the phone, the English interface and the rules panel. All of them come from `../screens/` (in `screens.zip`). The screenshots were taken automatically from version 1.4.0, in the light theme.
