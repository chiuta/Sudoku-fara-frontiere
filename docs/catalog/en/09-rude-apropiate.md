#### 99. Futoshiki · Futoshiki (`futoshiki`)

**Latin square with inequality signs.**

Every row and column contains the digits 1–N once; the signs < and > between the cells must be respected. A close relative of sudoku, without boxes.

#### 100. KenKen (Calcudoku) · KenKen (Calcudoku) (`kenken`)

**Latin square with arithmetic cages.**

Each row and column contains the digits 1–N once; each cage has a target and an operation (+, −, ×, ÷). Digits may repeat inside a cage if they are not in the same row or column.

<a id="strimko"></a>
#### 101. Strimko · Strimko (`strimko`)

**Chains instead of boxes.**

Every row, column and chain (circles joined by lines, connected also diagonally) contains each digit exactly once. There are no boxes. Sizes 4–7.

<table><tr><td align="center"><img src="../../screens/strimko_a.webp" width="300" alt="Strimko: starting puzzle"><br><sub>Starting puzzle (5×5 · medium · 5 givens)</sub></td><td align="center"><img src="../../screens/strimko_b.webp" width="300" alt="Strimko: after 4 steps"><br><sub>After 4 “Step by step” steps</sub></td></tr></table>

- **Last step explained by the app:** 2 (row 2, col. 1): all the other digits already appear among the marked cells (row, column, region or neighbour rule).
- **Code for the same puzzle:** `strimko-5-medium-2938744326` (paste it into “New game → Code”) · solver effort: no branching
