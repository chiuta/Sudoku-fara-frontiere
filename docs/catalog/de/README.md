# Katalog der Varianten (136)

[English](../en/README.md) · [Română](../README.md) · [Français](../fr/README.md) · [Italiano](../it/README.md) · [Español](../es/README.md) · [Português](../pt/README.md) · **Deutsch** · [Magyar](../hu/README.md)

[← README](../../../README.de.md)


Jede Variante hat unten: die Regeln aus dem Datenblatt, einen Screenshot mit einem echten, von der App erzeugten Rätsel (Größe 9×9, wo vorhanden, sonst die kleinste; Stufe „mittel“), einen zweiten Screenshot nach 4 Schritten „Schritt für Schritt“, die echte Erklärung des letzten Schrittes und einen Code, mit dem du genau dasselbe Rätsel neu erzeugst. Unter jeder Variante enthält eine „Vollständige Galerie“ (ausklappbar) die übrigen Screenshot-Arten: die Karte im Atlas und das Datenblatt, alle Größen, leicht/mittel/schwer, Auto-Notizen, Prüfung mit einer falschen Ziffer, die vollständige Lösung, das dunkle Thema, das Telefon, die Oberfläche auf Englisch und das Regelpanel. Alle stammen aus `../../screens/` (in `screens.zip`). Die Screenshots werden seit Version 1.4.0 automatisch erstellt, im hellen Thema.
