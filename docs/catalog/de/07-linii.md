#### 71. Paritätslinie · Parity line (`parityline`)

#### 80. Nebel · Fog of war (`fog`)

**Die Hinweise erscheinen beim Lösen.**

Die Hinweise (Thermometer, Pfeile, Renban) sind im Nebel verborgen. Das Rätsel ist so konstruiert, dass man, allein ausgehend von dem, was sichtbar ist, mit einfacher logischer Propagation (eindeutige Kandidaten) bis zum Ende weiterkommt. #### 88. Arithmetische Folge · Arithmetic progression (`progression`)

**Die Differenz zwischen Nachbarn ist konstant.**

Zusätzlich zu den klassischen Regeln ist auf einer Linie mit arithmetischer Folge die Differenz zwischen benachbarten Ziffern auf der ganzen Linie gleich (steigend oder fallend). Die Linie darf auch diagonal verlaufen; zwei aufeinanderfolgende Zellen dürfen nur dann dieselbe Ziffer enthalten, wenn sie sich keine Zeile, Spalte und keinen Block teilen.
