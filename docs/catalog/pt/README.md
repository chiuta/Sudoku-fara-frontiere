# Catálogo das variantes (136)

[English](../en/README.md) · [Română](../README.md) · [Français](../fr/README.md) · [Italiano](../it/README.md) · [Español](../es/README.md) · **Português** · [Deutsch](../de/README.md) · [Magyar](../hu/README.md)

[← README](../../../README.pt.md)


Cada variante tem a seguir: as regras da ficha, uma captura com um puzzle real gerado pela aplicação (tamanho 9×9 onde existe, caso contrário o mais pequeno; nível «médio»), uma segunda captura após 4 passos de «Passo a passo», a explicação real do último passo e um código com que regeneras exatamente o mesmo puzzle. Debaixo de cada variante, uma «Galeria completa» (expansível) tem os restantes tipos de capturas: o cartão do Atlas e a ficha, todos os tamanhos, fácil/médio/difícil, notas automáticas, verificação com um algarismo errado, a solução completa, o tema escuro, o telemóvel, a interface em inglês e o painel de regras. Tudo vem de `../../screens/` (em `screens.zip`). As capturas são feitas automaticamente a partir da versão 1.4.0, em tema claro.
