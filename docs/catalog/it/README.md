# Catalogo delle varianti (136)

[English](../en/README.md) · [Română](../README.md) · [Français](../fr/README.md) · **Italiano** · [Español](../es/README.md) · [Português](../pt/README.md) · [Deutsch](../de/README.md) · [Magyar](../hu/README.md)

[← README](../../../README.it.md)


Ogni variante ha qui sotto: le regole della scheda, una schermata con un puzzle reale generato dall'applicazione (dimensione 9×9 dove esiste, altrimenti la più piccola; livello «medio»), una seconda schermata dopo 4 passi di «Passo passo», la spiegazione reale dell'ultimo passo e un codice con cui rigeneri esattamente lo stesso puzzle. Sotto ogni variante, una «Galleria completa» (espandibile) contiene gli altri tipi di schermate: la scheda nell'Atlante e la scheda, tutte le dimensioni, facile/medio/difficile, appunti automatici, verifica con una cifra sbagliata, la soluzione completa, il tema scuro, il telefono, l'interfaccia in inglese e il pannello delle regole. Tutte provengono da `../../screens/` (in `screens.zip`). Le schermate sono create automaticamente dalla versione 1.4.0, in tema chiaro.
