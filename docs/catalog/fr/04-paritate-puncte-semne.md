#### 20. Pair–impair · Even–odd (`evenodd`)

**Carré = pair, cercle = impair.**

Les cases marquées d’un carré contiennent des chiffres pairs, celles marquées d’un cercle des chiffres impairs. Les autres règles sont classiques.

<a id="kropki"></a>
#### 21. Kropki · Kropki (`kropki`)

**Points : consécutifs ou double.**

Point blanc entre deux cases : les chiffres sont consécutifs. Point noir : l’un est le double de l’autre. Absence de point : ils ne sont ni consécutifs, ni dans un rapport de 1:2 (tous les points sont donnés).

#### 22. Consécutif · Consecutive (`consec`)

**Barre = consécutifs ; sans barre = non.**

Une barre entre deux cases signifie des chiffres consécutifs. Là où il n’y a pas de barre, les chiffres voisins ne sont pas consécutifs.

**X = somme 10, V = somme 5.**

<a id="batt"></a>
#### 25. Battenburg · Battenburg (`batt`)

**Parité en damier sur un 2×2.**

Un marquage en quatre carrés à l’intersection de quatre cases signifie que les parités alternent comme sur un échiquier (deux pairs et deux impairs, en diagonale). Aux intersections non marquées, les parités ne forment pas un tel motif.

<a id="ratio"></a>
#### 32. Rapport ×3 · Ratio ×3 (`ratio`)

**Points pour les paires de rapport 3:1.**

Sur l’arête entre deux cases adjacentes, un cercle avec 3 signifie que l’un des chiffres est le triple de l’autre (1–3, 2–6 ou 3–9). Selon la convention Kropki, s’il n’y a pas de cercle, les chiffres adjacents ne sont PAS dans un rapport de 3:1. Convention choisie par l’application : les sources décrivent vaguement les variantes « ratio », et ici « rapport » désigne strictement le facteur 3.

#### 37. Sans indices · Clueless (`clueless`)

**Seulement les points Kropki ; en général sans chiffres donnés.**

La grille n’a en général aucun chiffre donné (rarement un seul, quand les points ne déterminent pas à eux seuls la solution) ; toutes les autres informations viennent des points Kropki (blanc = consécutifs, noir = double, absence de point = aucun des deux). Le niveau de difficulté n’a aucun effet.
