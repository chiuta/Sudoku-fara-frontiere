# Catalogue des variantes (136)

[English](../en/README.md) · [Română](../README.md) · **Français** · [Italiano](../it/README.md) · [Español](../es/README.md) · [Português](../pt/README.md) · [Deutsch](../de/README.md) · [Magyar](../hu/README.md)

[← README](../../../README.fr.md)


Chaque variante comporte ci-dessous : les règles de la fiche, une capture avec un puzzle réel généré par l’application (la taille 9×9 là où elle existe, sinon la plus petite ; niveau « moyen »), une deuxième capture après 4 étapes de « Pas à pas », l’explication réelle de la dernière étape et un code avec lequel vous régénérez exactement le même puzzle. Sous chaque variante, une « Galerie complète » (dépliable) contient les autres types de captures : la carte dans l’Atlas et la fiche, toutes les tailles, facile/moyen/difficile, notes auto, vérification avec un chiffre erroné, la solution complète, le thème sombre, le téléphone, l’interface en anglais et le panneau des règles. Toutes proviennent de `../../screens/` (dans `screens.zip`). Les captures sont faites automatiquement depuis la version 1.4.0, en thème clair.
